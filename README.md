# Excel Sales Dashboard

An interactive Excel Sales Dashboard project built using Pivot Tables, Slicers, Conditional Formatting, and Data Analysis techniques in Microsoft Excel.

This project demonstrates practical Excel skills commonly used in Data Analyst and Business Analyst roles.

---

## Project Overview

The dashboard provides sales analysis across different:
- Regions
- Products
- Store Locations
- Customer Types

Users can interact with the dashboard using slicers and filters for dynamic analysis.
